SYS_01 // POLICY

3-Tier Shell Risk Classifier

ConfigManager.classify_command() tokenizes chained shell pipelines (;, &&, ||, |, subshells) into SAFE_READONLY, MUTATING_LOCAL, or PRIVILEGED_DESTRUCTIVE. Read-only diagnostics run unblocked in Supervised Review mode.

SAFE_READONLY MUTATING_LOCAL command_denylist
SYS_02 // LEDGER

Snapshot & Rollback Ledger

Every patch_file_content() and write_file_content() call records an entry in config/action_ledger.json with before/after SHA-256 hashes and a full snapshot in config/snapshots/ for instant /undo and /rollback <tx_id>.

/undo /rollback list SHA-256
SYS_03 // DOCTOR

6-Stage Application Crash Doctor

diagnose_and_heal_app() resolves binaries and .desktop targets, audits SingletonLock and Crashpad/*.dmp, greps session logs, checks X.509 .pem expiry via OpenSSL, and patches JS bundles with .bak backups.

openssl x509 SingletonLock .bak
SYS_04 // SKILLS

Pluggable Markdown Runbooks

SkillsLoader discovers skills/*.md YAML-frontmatter runbooks (nginx-tls-audit, postgres-doctor, gpu-cuda-doctor, git-recovery) and injects matching domain procedures directly into the ReAct system prompt.

/skills skills/*.md auto-inject
SYS_05 // INFRA

Container, Systemd & Net Audit

Dedicated tools for Docker/Podman container inspection and automatic Exited (137) log tailing (/containers), failed unit & journald inspection (/systemd), socket/firewall audit (/net), plus /disk, /gpu, /tls, and /git.

/containers /systemd /net /gpu

Proactive Watchdog & GTK3 DnD

DIAGNOSE_AND_HEAL_APP // 6-STAGE PIPELINE
01 find_binaries Resolves PATH, ~/.local/bin symlinks, and Freedesktop .desktop launchers.
02 inspect_locks Audits stale SingletonLock sockets and recent Crashpad/*.dmp minidumps.
03 scan_crash_logs Extracts ConnectError, TLS handshake failures, and segfault traces from latest session logs.
04 audit_certs Executes openssl x509 -noout -dates -checkend 0 across bundled .pem certificates.
05 atomic_patch Snapshots target bundle into config/snapshots/ + .bak and patches nodeOptions.
06 verify_report Verifies patch integrity and streams root-cause evidence to the GTK3 Chat Studio.
05 // BUILD_SPECIFICATION

Ubuntu Installation & Verification

Native PyGObject (GTK3) + PyCairo • Zero Electron overhead

Run natively on Ubuntu 22.04, 24.04 & 25.10.

Tchiko uses system python3-gi and python3-gi-cairo packages for direct X11/XWayland RGBA compositing, logging all runtime output to logs/tchiko.log.

Security Policy 
# 1. Install system GTK3 & Cairo bindings
sudo apt update && sudo apt install -y \
  python3 python3-venv python3-gi python3-gi-cairo gir1.2-gtk-3.0 xclip

# 2. Clone repository & run verification suite (11 unit tests + 4-stage self-test)
git clone https://github.com/ZYNIQ-SOLUTIONS/Tchiko-Assistant-Sysadmin-companion.git
cd Tchiko-Assistant-Sysadmin-companion
make self-test && make test

# 3. Launch desktop companion (streams logs to logs/tchiko.log)
./run_tchiko.sh
