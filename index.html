01 · Policy

3-Tier Shell Risk Classifier

Tokenizes chained shell pipelines into SAFE_READONLY, MUTATING_LOCAL, or PRIVILEGED_DESTRUCTIVE. Read-only diagnostics run smoothly without prompts in Supervised Review mode.

classify_command() command_denylist
02 · Ledger

Snapshot & Rollback Ledger

Every file patch and write records SHA-256 hashes and a pre-edit snapshot under config/snapshots/, enabling instant rollback via /undo or /rollback.

/undo action_ledger.json
03 · Crash Doctor

6-Stage Application Crash Doctor

Resolves binaries and desktop launchers, checks SingletonLock and Crashpad dumps, scans session logs, verifies X.509 certificates via OpenSSL, and patches bundles safely.

Pro 01 · Experiences Pro

Experiences: solve it once, reuse it

When Tchiko finishes a task, Pro turns the working steps into a named, parameterised Python Experience. The next time a similar request comes in, the agent calls that Experience instead of working the problem out again.

Each run records which Experiences were used and how the task went. The Learning Curve shows that history, so you can see what Tchiko has learned on your machine and how often it reuses it.

Install the Community Edition on Ubuntu

Native PyGObject (GTK3), PyCairo, and zero-dependency Tchiko RC

Run natively on Ubuntu 22.04, 24.04 & 25.10.

Uses system python3-gi and python3-gi-cairo packages for direct X11/XWayland RGBA compositing, streaming runtime logs to logs/tchiko.log and serving Tchiko RC over local TLS on port 8765.

Security Policy 
# 1. Install system GTK3 & Cairo bindings
sudo apt update && sudo apt install -y \
  python3 python3-venv python3-gi python3-gi-cairo gir1.2-gtk-3.0 xclip

# 2. Clone repository & run verification suite (includes RC crypto & sigil E2E)
git clone https://github.com/ZYNIQ-SOLUTIONS/Tchiko-Assistant-Sysadmin-companion.git
cd Tchiko-Assistant-Sysadmin-companion
make self-test && make test

# 3. Launch desktop companion (or open Tchiko RC pairing / headless server)
./run_tchiko.sh              # Desktop + RC server
make remote                  # Desktop + Tele-Command Sigil window
python3 main.py --remote     # Headless HTTPS/WSS server
