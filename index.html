Quick Start on Ubuntu

Up and running in 30 seconds.

Uses Ubuntu’s native `python3-gi` and `python3-gi-cairo` bindings for zero-overhead RGBA compositing across X11 and XWayland.

Read Architecture
bash • ubuntu 22.04 / 24.04 / 25.10 MIT Open Source 
# 1. Install native GTK3 & Cairo bindings
sudo apt update && sudo apt install -y \
  python3 python3-venv python3-gi python3-gi-cairo gir1.2-gtk-3.0 xclip

# 2. Clone, verify & launch Tchiko
git clone https://github.com/ZYNIQ-SOLUTIONS/Tchiko-Assistant-Sysadmin-companion.git
cd Tchiko-Assistant-Sysadmin-companion
make self-test && make test
./run_tchiko.sh
