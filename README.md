## ⚡ Overview

**Tchiko Assistant** (`Tchiko-Assistant-Sysadmin-companion`) is an open-source, always-on-top floating AI desktop companion for **Ubuntu Linux**, inspired by the mythical **Dijiang (Hundun)** from *Shang-Chi’s* realm of Ta Lo and powered by the **Google Antigravity SDK (`google-antigravity`)**.

Designed in a signature **Snowy White, Crimson Red, and Velvet Black** palette with real-time **Spring-Jelly Squash-and-Stretch Physics**, Tchiko floats above your desktop windows and executes real Linux & DevOps sysadmin tasks on command.

---

## 🖱️ Signature Desktop Interactions

| Interaction | Action |
| :--- | :--- |
| **Middle-Click (Scroll-Wheel Click) on Tchiko** | Toggles the compact **Quick Input Bar (`Ask Tchiko... ↵`)** directly below Tchiko and focuses it immediately. |
| **Press `Enter` (`↵`) in Quick Input** | Sends your prompt, hides the input bar, and streams Tchiko's reply inside a **Talking Speech Bubble** right above Tchiko (with 1-click `📋 Copy`). |
| **Single Left-Click on Tchiko** | Opens / toggles the full **Tchiko Chat & System Studio** window (`💬 Chat`, `⚡ System Studio`, `🧠 Activity`). |
| **Left-Click + Drag** | Moves Tchiko anywhere on your Ubuntu screen with live leg-dangle & velocity physics (auto-saves position). |
| **Hover / Rub Cursor Over Tchiko** | Pets Tchiko's fluffy coat — squishes like a marshmallow and emits musical chirp notes (`♪`). |
| **Scroll Wheel Up / Down** | Cycles through all **10 interactive pet emotions & tricks** (`love`, `happy`, `roar`, `wing_slash`, `excited`, `thinking`, `executing`, `idle`, `sleepy`, `dizzy`). |
| **Double Left-Click / Right-Click** | Opens **Tchiko Settings & Permissions** or the quick **Context Menu**. |

## 🚀 Quickstart

```bash
# 1. Clone the repository
git clone git@github.com:ZYNIQ-SOLUTIONS/Tchiko-Assistant-Sysadmin-companion.git
cd Tchiko-Assistant-Sysadmin-companion

# 2. Run automated self-test (verifies Cairo SVG renderer, Antigravity SDK & Linux toolkit)
python3 main.py --self-test

# 3. Launch Tchiko floating desktop companion
./run_tchiko.sh
```
